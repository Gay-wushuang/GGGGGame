# D 开发与验收清单

D 使用 DSH，按 D01～D11 交付玩家侧功能。首轮验收 P0、P1，P2～P4 保留完整范围，由 B 后续安排。阶段编号用于 D 的验收，灰盒制作阶段按原文引用。[D Agent 工作规范](D_Agent工作规范.md) · [D 原交接单](D_独立功能实现.md)

D 在本方测试场自测并提交证据，B 单独验收 D 的结果。P0～P2 可独立执行。P3、P4 需要 E 提供对应真实服务，D 交玩家操作及呈现结果。本地编译、模拟服务、本地真实服务、正式联机各用对应证据，玩法以实际运行为准。
