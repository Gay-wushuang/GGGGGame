# D/E 开发与验收清单

首轮派发 P0 和 P1。P2～P4 保留完整任务，由 B 安排后续验收。下列阶段用于 D/E 协作检查，引用灰盒制作阶段时沿用灰盒第 12 节编号。

验收依据为 [灰盒 v0.5](../灰盒设计_v0.1.md)、[API v0.6](../API与联调契约_v0.2.md)、[D 交接单](D_独立功能实现.md)、[E 交接单](E_独立功能实现.md) 和 [共享 C# 契约](../../who-sent-this-guy/shared/contracts/)。工作方式见 [Agent 协作规范](../../AGENTS.md)。

## P3 D/E 真实服务联调

**状态 未开始** · **验收 D/E 同场复跑，B 核对确认链路和单机闭环**

- D（D04～D08、D11）把玩家操作切到同版真实服务，按确认状态更新提示、库存和 HUD。
- E（E01～E08、E09）提供本地权威入口、真实物理与同版确认结果，统一接入共享类型、工程设置和正常主场景。

1. 首次仅接凝胶回收。E 用一把枪发射真实胶块并建立有效连接，回收者的枪留一个容量位置。D 瞄准发出 `RequestRecoverGel`，记录 `Key`、`GunId`、`TargetGelId` 和 `ExpectedGunRevision`。
2. 核对 E 一次提交拆除目标胶块及相关连接，回收者库存增一，D 按同一确认版本刷新 HUD。再测 `GelGunFull` 拒绝且实体和连接保留、两人抢收仅一次成功且 D 显示确认原因、同键重传保持原结果。
3. 回收链路通过后，实际接入驾驶、抓货、订单、选路、加油、事件和恢复。用 D 的人物在正常场景完成单人室外装运卸，核对终点交付和结算，再进入正式联机验收。

**证据**为两侧同一用例的请求编号、玩家/枪/胶块标识、确认版本、连接及库存前后值与 HUD 录像，以及正常场景的启动方式和单机装运卸记录。[API 第 11 节](../API与联调契约_v0.2.md#11-de-并行开发约定)
