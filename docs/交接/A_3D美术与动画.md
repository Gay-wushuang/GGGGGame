## 1. 视觉方向与尺度

A 已制作人物与车辆基础模型，B 已确认当前比例并同意沿用整体风格。后续资产采用现有圆润、简洁、低复杂度的卡通造型，视觉方向参考《人类一败涂地》。A 可直接沿此方向建模并完善配色、装饰与材质，重要方案交 B 审核。1～4 名玩家共用一套基础模型，提供四种易区分的材质配色。头部、躯干、手臂和腿的结构预留后续绑定条件，保留头部、身体与手部的独立显示结构。

单位为 m，三维代理尺寸统一为宽 X × 高 Y × 长 Z，Y 向上、前向 −Z，根节点单位缩放。

| 对象 | 制作基准 |
|---|---|
| 人物 | 站高 1.20，头直径 0.80，视觉宽 0.96，碰撞直径 0.80，蹲高 0.85 |
| 眼点 | 站姿 1.02，蹲姿 0.70，相对脚底 |
| 整车 | 宽 3.00、高 3.50、长 8.80，轮胎等部件在收纳行驶状态计入外宽 |
| 后舱 | 净宽 2.70、净高 2.68、净长 5.80，地板顶面离地 0.70，顶棚厚 0.12 |
| 驾驶区空间参考 | 净宽 2.70、长约 2.20，实体隔断连通后舱 |
| 门洞 | 隔断净宽 1.10 × 净高 1.90，后门净宽 1.80 × 净高 2.00 |
| 斜板与车轴 | 后斜板宽 1.80、水平伸出 2.10，轴距 5.80，轮径、胎宽与轮距待车控标定 |
| 道路 | 总净宽 6.00，标线两侧各 3.00，弯道中线半径 20.00 为灰盒初值 |

地板顶高 0.70 + 后舱净高 2.68 + 顶棚厚 0.12 = 车高 3.50 m。道路与会车采用灰盒第 5.3 节的全幅通行、避车港口径。按空舱四人和临时三货加三人纵向错列核对静态占位，量取门框、把手和开启后门扇的占用，分别记录视觉宽与碰撞宽。动态通行见第 5 节。

## 4. 动画与制作要求

本节列入 P2，待基础静态模型齐备后再安排。人物采用**正常角色动画配合局部物理反馈**。行走、奔跑、搬运按稳定可控的方式接入。急刹、碰撞和翻车时，D/E 可结合物理状态接入失衡、摔倒、适度布娃娃反馈和起身。

共用一套人物骨架，附手部、躯干和腿脚的动作映射。基础十动作沿用 idle、walk、run、crouch_idle、crouch_walk、carry_idle、carry_walk、seated、grab、release。前八项可循环，抓松时长作为样例，30 fps 原地采样，位移由控制器驱动。

| 人物动作 | A 的最低交付与简化方式 |
|---|---|
| 跳跃与落地 | 起跳及空中姿态、落地缓冲短段，接实际起跳与接地状态 |
| 推动与拖拽重物 | 推、拖两种上身姿态和手部对齐参考，可与步态混合 |
| 驾驶握盘与转向 | 就座握盘及左右转向姿态参考，可用双手 IK 跟随方向盘握点 |
| 失衡、摔倒与起身 | 失衡和倒地过渡参考、起身或恢复短段。碰撞与翻车时由 D/E 将动作与实际物理状态混合 |
| 凝胶枪持枪、喷射与回收 | 持枪姿态及喷射、回收手部短段，可共用上身骨骼与持枪姿态 |

单鸡交待机及少量可复用小动作，如点头和挪步。逃出与抓回的表现随触发与操作方案确认后细化，可优先复用这些短段。空缸后续以低成本外观区分完好、裂纹与破碎。

凝胶喷射交枪口短效和单块离枪表现。吸回交剥离、拉伸、收缩和吸入表现，可用模型或材质动画，时长与幅度待确认。P3 按确认的 StoredUnits 和 CapacityUnits 表现储量，按 GelFired 和回收开始、成功、取消状态驱动表现。满枪拒收时保留原胶块和储量显示。粘连时各块保持独立轮廓和发射枪颜色。任一队友回收后，更新回收者枪的储量表现，重新发射采用当前枪颜色。E 按独立黏性连接点和物理约束处理。

| 事件或事故 | 最低表现交付 |
|---|---|
| UFO | 飞碟移动或悬停、吸取光束与地面作用圈，母牛悬浮、旋转并沿光束吸走。飞碟和母牛可用节点位移与旋转 |
| 龙卷风 | 旋转风柱、风向与预警表现、少量可复用飞散杂物，同一母牛可用基础升起和翻转姿态表现卷起 |
| 骑牛飞车党 | 盗贼骑乘、母牛移动、接近车辆、尝试操作后门或拖货、离开或撤退。骑乘循环、门闩与抓货短姿态可配程序位移复用 |
| 物理翻车 | 人物沿用本节失衡、倒地与恢复表现。P3 复用正常车体、车轮、车门与代理，验证各部件随整车物理翻转 |

事件表现可由骨骼、节点变换、可复用短段和简单特效组合，按实际事件阶段启停及取消。
