## 1. 视觉方向与尺度

采用夸张、低细节、清楚可读的送货喜剧。人物默认 **1.5 头身**，1 头身可作后续外形对比。头部和身体为独立可见性部件，本地第一人称隐藏头部。

单位 m，三维尺寸统一为 **宽 X × 高 Y × 长 Z**，Y 向上、前方 -Z，根节点单位缩放。

| 对象 | 统一基准 |
|---|---|
| 人物 | 站高 1.20，头直径 0.80，视觉宽 0.96，碰撞直径 0.80，蹲高 0.85 |
| 眼点 | 站姿 1.02，蹲姿 0.70，相对脚底 |
| 整车 | 宽 3.00、高 3.50、长 8.80；轮胎等外伸部件也在 3.00 m 最大宽度内 |
| 后舱 | 净宽 2.70、净高 2.68、净长 5.80；地板顶面离地 0.70，顶棚厚 0.12 |
| 驾驶区 | 净宽 2.70，长约 2.20；实体隔断连接后舱 |
| 门洞 | 隔断净宽 1.10 × 净高 1.90，后门净宽 1.80 × 净高 2.00 |
| 道路 | 总宽 6.00，标线两侧各 3.00，弯道中线半径 20.00 |

0.70+2.68+0.12=3.50，顶棚有实体厚度。道路单车道与车同宽，不具备常规双车会车余量。四人及六货加三人按纵向错列检验，旧五人并排条件取消。视觉宽与碰撞宽分别测量，不能缩小碰撞掩盖空间冲突。

## 3. 挂点与控制

| 资源 | 必须保留的语义节点 |
|---|---|
| 人物 | Head、Body、Hands、HandGripLeft/Right、EyeStanding、EyeCrouching |
| 车辆 | BodyShell、Cabin、CargoBed、CargoInteriorBounds、CabinPartition、PartitionDoor、RearDoor、RearEntry、RearPin |
| 座位和镜头 | SeatDriver、SeatPassenger、ExitLeft/Right、CameraDriveTarget；座位与步行人数总计最多四人 |
| 音频和轮位 | AudioEngine、AudioListenerDriver、WheelFL/FR/RL/RR、AudioTireFL/FR/RL/RR |
| 货物 | 底面中心原点、GripHintLeft/Right；CageDoor、WaterSurface、Fuse、WarningAnchor |
| 事件 | UFO Beam/InfluenceBounds，母牛 RideAnchor，哈吉米 TireAttachAnchor，龙卷风 InfluenceBounds |

真实命中表面建立抓点，GripHint 只提供视觉提示。特效范围对应 E 的有效范围；母牛表演与损伤判定分开，空中表演不能产生未预警碰撞。

## 4. 动画和制作要求

基础十动作：idle、walk、run、crouch_idle、crouch_walk、carry_idle、carry_walk、seated 为循环，grab 0.35 s、release 0.30 s 为短动作。事件允许程序变换与简单姿态；首轮不强求额外精细骨骼动画。30 fps 原地采样，位移由控制器驱动，交互动作按确认状态播放。

优先共享纯色材质，纹理首轮最大 1024²。角色/车/货物的 5000/8000/1000 三角形仅作成本参考；报告实际三角形、材质槽、骨骼、纹理、透明面和体积，B 按实测修订。鱼缸透明材质须在实际渲染器检查，排序失败时用不透明蓝水占位保证可读性。

## 5. 交付与验收

先 A01～A05、A11 验证人物车货，再 A06～A10、A17 支撑路线，最后 A12～A16 配合五事件。每批附前/侧/顶图、真实包围盒、挂点清单、导入预览和问题记录。门框、轮罩、六货与三人纵向通道须用实际碰撞复核；静态站得下不能作为动态操作通过证据。

B 接收模型和可制作性反馈，D/E 验证运行表现；按策划、文档、实践、CI 测试、审查五条线记录状态，尚未执行的检查明确记为待验。
