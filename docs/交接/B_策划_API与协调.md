## 1. 本轮规则与参数状态

1～4 人自由分工，单人可装货、驾驶、处理途中情况、卸货与结算。人物采用正常角色操控与短时局部物理反馈。使用实体手册、常态第一人称、驾驶第三人称、每人最多抓持一个物理实体、每实体最多两人协作、后舱活动及定速巡航。关卡提供路线选择、迟到继续送货与基础结算，商店仅提供室外加油。

| 项目 | 当前采用与状态 |
|---|---|
| 人物 | 已确认默认 1.5 头身，站高 1.20 m，头直径 0.80 m，视觉宽 0.96 m，碰撞直径 0.80 m，站姿眼高 1.02 m，蹲高 0.85 m、眼高 0.70 m |
| 车舱与道路 | 已确认车长宽高 8.80 × 3.00 × 3.50 m，后舱净长宽高 5.80 × 2.70 × 2.68 m，道路总净宽 6.00 m。门洞、斜板、顶棚与地板按主设计第 5 节 |
| 货物 | 本轮只用一只鸡，默认装笼，鸡、笼体同单且按实体分别限员。鸡可逃出，实际离笼后可独立抓持和回笼。试装为单笼一鸡、一空鱼缸、一件直径 0.65 m 的球形货物。首关清单和品质规则待确认，质量、运费与空缸碰撞阈值待标定 |
| 单鸡交付与鸡笼 | 鸡为交付目标，配套笼体实际卸入室外收货区且合格时算归还。两者齐到正常交付。仅鸡到达时可返回取笼或确认只交鸡，包装未归还费按同单货物单列一次。只交鸡后笼体原位保留碰撞与载荷，进入下一关时清理，本关重试恢复关前鸡与笼 |
| 凝胶枪 | 每人独立枪，单块一单位，回收到执行者枪，重射采用当前枪颜色，满枪拒绝，同尺寸胶块以黏性接点和弹性约束固定，粘连后保持独立，抢收只成功一次。键位、持货切换、目标范围、连接数量/距离、过载及计重待确认，容量、初始量、尺寸、射程、弹性、强度和阻尼待标定 |
| 路线与事件 | 沿用八节点拓扑，路线节点 D/F 使用当前事件候选，节点 E 为加油站。UFO、龙卷风、骑牛飞车党分别提供实际测试入口，翻车按实际物理事故独立验证，单人可恢复。时序、外力、次数、停稳条件与恢复操作待标定或验证 |
| 场景 | B 确认路线与作业点配置。仓库、交付站和加油站使用建筑外观。室外完成装货、订单板签单、卸货交付与加油 |
| 订单经济 | 720 s、起始 500 元与 35 L、油箱 60 L、加油价 5 元/L、旧扣薪档位与上限均为待标定或验证种子。订单件数、总质量和满品质运费按实际清单计算 |
| 网络 | E 实现正式会话及房主端裁决，D 接玩家侧。传输方案待 B 评审，联机性能与误差容差待验证 |

临时操作采用本人先松手再切枪，保留队友抓持。临时凝胶目标采用货物、可粘货舱结构和独立胶块，具体表面待 B/E 确认。基础二值品质和首关试装也按待确认配置管理。B 在实测后发布采用值、状态及版本，再同步到受影响交接与接口。

本轮范围和验收采用灰盒第 1.4、12 节，后续方向见第 13.2 节。木箱、圆桶和重物可作为物理回归样本。[灰盒设计 v0.5](../灰盒设计_v0.1.md)

## 5. 跨包验收口径

- **灰盒 P1 基础物理**核对人物、车体、地板、斜板、后门门闩及净开口。验常规操控与局部反馈、空舱四人、临时三货加三人、单人装卸、双人协作抓取与偏载。试两人抓笼且第三人抓离笼鸡，并核对笼内抓持限制。司机失联后安全制动。
- **灰盒 P1 凝胶与载荷**核对 E 同一提交更新胶块、相关连接和库存，D 按确认库存显示。检查接点与弹性、跨玩家回收、重射换色、满枪拒绝、抢收只成功一次、重传和断线释放未提交锁与预留。
- **灰盒 P2 送货闭环**验室外签单、装卸、交付和加油，全分支可达。单鸡逃出仍可找回，回笼沿用同一订单项，空笼保持未交付。分别验完整归还、返回取笼及只交鸡。只交鸡确认后费用单列一次，实发不低于 0。未归还笼保持原位与车载质量，验证换关清理及本关重试恢复。核对出库起钟、迟到继续、品质运费与分币结算、加油原子交易，以及独立物理翻车和单人恢复。恢复保留确认的货损和订单。
- **灰盒 P3 三个特殊事件**分别实测 UFO 的受力和吸牛、龙卷风的横向力与主动避让、骑牛飞车党的门闩与可取货物。验驾驶、关门和凝胶保护等已确认应对，以及退场和取消清理。
- **灰盒 P4 整合与标定**分开记录模拟、本地权威和正式联网。验 1～4 人闭环、2～4 人状态一致性、单鸡交付选择并发与取消、重复请求、掉线重连、回合重置及音频循环与去重，记录参数和性能。按灰盒 V01～V23 和契约第 10 节登记结果与待验项。
