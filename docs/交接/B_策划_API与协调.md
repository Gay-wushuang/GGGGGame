# B 的策划、API 与协调总表 v0.4

更新日期：2026-11-15。本次将项目转为**限时送货、路线抉择、货物保护与荒诞突发事件**。主规则见[灰盒设计 v0.4](../灰盒设计_v0.1.md)，接口见[API v0.4](../API与联调契约_v0.2.md)。沿用原路径，正文和五份交接单同步升级；旧版“API 保留原稿待同步”说明作废。

## 1. 已确认方向与本轮采用值

用户要求人物 1 或 1.5 头身、车宽 3 m、道路宽 6 m；参考 Steam《我们到了吗？》的合作驾驶体验，做以送货和突发场景为主的差异化玩法。关卡内在时限送达、多线路节点抉择、超时扣工资，并用收入修车、买油、道具和升级。首批货物鸡笼/鱼缸/炸弹；五事件为 UFO 吸车与母牛、龙卷风飞牛、骑牛飞车党拔车销偷货、母牛雨、哈吉米吸附轮胎。

保留此前未冲突要求：1～4 人、单人可完成、实体手册多人独立阅读、常态第一人称/驾驶第三人称、同物件多人共同作用、简单驾驶与巡航、平稳后舱活动、设置改键。角色职责由玩家自由安排，不设强制双人机关。

| 项目 | 本轮设计初值 |
|---|---|
| 人物 | 默认 1.5 头身，站高1.20/头直径0.80/视觉宽0.96/碰撞直径0.80/眼高1.02；蹲高0.85/眼高0.70 m |
| 车辆 | 长8.80×宽3.00×高3.50 m，含轮胎最大宽3.00 |
| 后舱 | 净长5.80×宽2.70×高2.68，地板0.70，顶棚0.12 m |
| 门洞 | 隔断1.10×1.90，后门1.80×2.00 m，均为净宽×净高 |
| 道路 | 总宽6.00、每侧标线车道3.00；与车等宽，无法正常双车会车，弯道允许跨线 |
| 标准货物 | 两鸡笼18 kg、两鱼缸35 kg、两炸弹45 kg，总196 kg |
| 订单经济 | 首关720 s、共享初始500元、满额1520元；超时每起30 s扣20，封顶当前品质工资80% |

数值除用户明确的车宽/路宽与人物风格外均为可调种子。B 维护唯一采用表；改值须同步主文档、API、A/C 制作单、D/E 功能单和 greybox 规格，不能只改其中一处。

## 5. 经济、路线和事件必须守住的语义

订单从司机装货后主动出库开始，直到最后一件交付或损失确认停表。运输、选路、维修加油、事件和卸货都计时；零秒后能继续送。F=sum(fee×q)，L=max(0,t-T)，扣薪P=min(0.8F,20×ceil(L/30))，实发round(F-P)。品质、损失与结算只由 E 裁决；本单只摘录计算口径，细节和样例以主文档为准。

路线为有限有向无环图，节点展示服务、预计时间/油量与已知风险；司机在分叉停车预选出边、停车点击确认提交后权威锁定，不能回退刷奖励。交易原子扣共享钱包，单号/货物/请求/事件有稳定标识并去重。重试恢复本关起点钱包和库存检查点，不保留本次奖励或消费。零油/零HP/无钱有免费恢复路径，付费道具不是处理事件唯一解。

事件统一 Warn→Active→Recovery→Resolved；至少6s预警，主事件最多一个，哈吉米也不与主事件叠，结束后45s冷却。UFO降低有效受力但不改实际质量统计；飞车党须先拔销再偷松散货，最多一件；母牛雨落点提前2s；哈吉米最多两只、有免费停车移除且不锁轮。母牛表演与真正危险碰撞分开。

## 6. 五条工作线与验收

| 线 | 每批回交 |
|---|---|
| 策划 | 对照实际行为、参数差异、单人完成性、路线和事件决策是否有价值 |
| 文档 | 运行入口、代码/配置映射、API和资产版本、变更及已知限制 |
| 实践 | 可运行增量、必要素材接入、问题修复 |
| CI测试 | 实际执行版本、构建/启动/边界/幂等测试、失败与未执行项 |
| 审查 | D/E互审、B跨包复核，问题处理与复测结果 |

必须验收：人物和门洞真实碰撞；空车4人/六货3人纵向活动；单人三货装卸；双人不同抓点/松手/断线；巡航制动即时取消；720s边界、零品质/全损工资、交易并发、重复结算；路线全可达；五事件免费反制和恢复；重连重置清理；零油零HP不软锁。API 第10节提供批次细目，主文档提供玩法验收。

## 7. 技术与平衡开放项

Godot .NET/SDK、网络传输、物理权威和测试框架尚需工程验证；场景原语不代表 C# 已就绪。车轴距/轮距和质量、抓取辅助、低速稳定、货物损伤、事件受力、服务耗时、关卡预算按实际试玩标定。B 发布采用结论和受影响文件，避免成员按旧值分别实现。
