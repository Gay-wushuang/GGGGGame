# 《这货谁送的？》

2026-11-15 · 送货玩法重构 v0.4

核心方向：1～4人合作限时送货，根据鸡笼、鱼缸、炸弹的运输要求选择路线，在UFO、龙卷风、骑牛盗贼、母牛雨和哈吉米吸轮胎等突发事件中保住货物与工资；通过修车、买油、道具和升级安排班次预算。

用Godot 4.7打开`who-sent-this-guy/project.godot`，F5运行比例与事件预览。N查看路线草案，8循环事件，9清除事件。人物默认1.5头身，车宽3米，道路总宽6米。

当前可运行内容为比例、装载空间、观察工具、路线概念图及事件循环动画。完整送货、驾驶、经济、多人联机和事件应急系统按文档继续实现。
