# 《这货谁送的？》比例与事件预览 v0.4

更新日期：2026-11-15。使用 Godot 4.7 打开本工程，运行主场景 `greybox/scale_validation.tscn`（F6运行当前场景，F5运行工程）。

本轮把人物改为1.5头身，把车辆最大外宽改为3米、道路总宽改为6米，并用鸡笼、鱼缸、炸弹替换旧标准货物。另加入层状路线概念图和五种荒诞事件循环动画。完整玩法规格见 [主设计文档](../../docs/灰盒设计_v0.1.md)。

## 当前尺寸

1世界单位=1米，Y向上，车辆前向-Z。向量与货物尺寸按宽X、高Y、长Z。

| 对象 | 尺寸 |
|---|---|
| 人物 | 站高1.20、蹲高0.85；头径0.80；视觉宽0.96；碰撞直径0.80米 |
| 眼高 | 站姿1.02 / 蹲姿0.70米 |
| 运输车 | 长8.80 × 宽3.00 × 高3.50米，含轮胎最大外宽3.00米 |
| 后舱 | 净长5.80 × 净宽2.70 × 净高2.68米 |
| 地板 / 顶棚 | 地板顶面离地0.70米；实体顶棚厚0.12米 |
| 门洞 | 隔断1.10 × 1.90米；后门1.80 × 2.00米 |
| 道路 | 总宽6.00米，单道3.00米；左右弯中线半径20米 |
| 车轮 / 斜板 | 轮距2.70米、胎宽0.30米、轴距5.80米；后斜板伸出2.10米 |
| 场地 | 100 × 80米；装卸区各14 × 14米 |

两辆3米宽车辆不能在6米道路上常规会车：单道没有横向余量，长车过弯还会跨线。正式关卡必须安排避让湾、错峰放行或停车让行；本场景是尺度检查，未验证真实转向轨迹。

## 六件货物与预置

| 类型 | 数量 | 宽 × 高 × 长 | 单件质量 |
|---|---|---|---|
| 鸡笼 | 2 | 0.80 × 0.70 × 0.60米 | 18千克 |
| 鱼缸 | 2 | 0.90 × 0.75 × 0.65米 | 35千克 |
| 炸弹 | 2 | 0.65米立方包络，含底托与引线 | 45千克 |

总质量196千克。灰盒以笼栏和鸡、蓝色透明水缸和鱼、黑色球体和引线区别类型；这些是几何外观，不会产生真实惊吓、漏水、爆炸或物品交互。

六种预置为地面对照、六货三人、鸡笼叠放、空舱四人、三人超宽、六货装车。合理装载将两鸡笼两鱼缸纵向放在左侧，两炸弹放右侧，中央最窄通路1.15米，三名舱内人物纵向分布。鸡笼叠放仅验证1.40米堆高的几何，是否允许叠放以玩法规格为准。

“三人超宽”故意展示无效布局：3 × 0.96 = 2.88米，大于2.70米内宽。此样本不能作为三人横排可用的验收依据。第五个旧尺寸样本节点保留兼容，但不显示、不启用碰撞。

## 事件与路线预览的边界

- UFO：光束、母牛上升和车体轻微悬浮，舱内样本人货随车一起升降。升降是纯视觉位移，未改变或模拟质量、惯量和真实受力。
- 龙卷风：风柱与母牛绕柱飞行。
- 骑牛飞车党：骑牛者接近车尾、红色车销拔出和黄色偷货占位箱。
- 母牛雨：分散落点圆圈与循环降落母牛。
- 哈吉米：最多两只猫从路边接近轮胎并停留附着。

这些动画用于评审构图和辨识，未实现事件AI、碰撞伤害、反制操作或奖励。事件与关卡正式规则在主文档中定义。

N打开的八节点图展示“仓库 → 三条候选路线 → 交付/补给节点 → 终点”。只支持预选查看与连线高亮，不会触发真实装货、订单、服务交易或关卡切换。

## 工程文件

- `scale_spec.gd`：统一尺寸、货物、摆放与人物姿态。
- `build_scale_scene.gd`：生成实际可编辑的场景几何。
- `scale_validation.tscn`：已生成的主场景。
- `scale_viewer.gd`：观察、预置、站蹲、门、界面与预览入口。
- `event_preview.gd` / `route_map_preview.gd`：事件动画与路线概念图。
- `validate_scene.gd`：检查实际几何、装载分离、门洞、视角、预览及清理，并可保存截图。
